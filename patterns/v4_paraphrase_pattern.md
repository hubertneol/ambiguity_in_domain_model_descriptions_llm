# Pattern Name
V4 – Paraphrase Transformation Pattern

## Problem and Intended Outcome
The purpose of this pattern is to rewrite a natural-language domain description using different wording and/or sentence structure while preserving the complete model-relevant meaning.

The transformed description should be semantically equivalent to the baseline with respect to the intended UML domain model.

## Motivation
This pattern is used to investigate whether linguistic reformulation alone influences the UML domain model generated by a large language model.

If the model is robust to paraphrasing, the generated domain model should remain structurally similar despite changes in wording.

## Structure and Participants
Input:
- one original natural-language domain description

Transformation:
- change lexical choices,
- change sentence structure where appropriate,
- preserve all model-relevant semantics.

The transformation must preserve:
- classes,
- attributes,
- relationships,
- cardinalities,
- constraints,
- explicitness or implicitness of information.

Constraints:
- do not add model-relevant information,
- do not remove model-relevant information,
- do not introduce ambiguity,
- do not introduce semantic anomalies,
- do not make explicit information implicit,
- do not make implicit information explicit,
- change linguistic realization only.

Output:
- one paraphrased domain description,
- no explanation or commentary.

## Realized Prototype
Input:

"A customer places one or more orders. Each order contains one or more products."

Output:

"One or more orders may be placed by a customer, and every order includes at least one product."

## Consequences

### Strengths
- keeps model-relevant semantics constant,
- isolates linguistic formulation as the manipulated factor,
- provides a useful robustness condition.

### Weaknesses
- perfect semantic equivalence is difficult to guarantee,
- paraphrasing may unintentionally alter emphasis or explicitness,
- manual checking may be needed to confirm that no model-relevant information changed.
